# Справочник городов

Выбор доступен только при регистрации и в «Настройки → Личные данные».
CityPicker использует GET /cities, ищет по названию и региону, учитывает е/ё.
При регистрации отправляется реальный cityId из API; в личных данных город
сохраняется кнопкой «Сохранить» через PATCH /profile. Заказы получают город
из профиля существующим серверным механизмом.

## Данные

В репозиторий включён снимок 1134 записей, полученный 2026-09-13:

- Названия: https://github.com/pensnarik/russian-cities/tree/e4ba0919bcdfb00debe96798a0810d9091a7bfc2
- Полные названия регионов и часовые пояса: https://github.com/arbaev/russia-cities/tree/d6ec3167d95029f489df1caebdbb17304264f379

Используются только факты из JSON. Это не онлайн-реестр ГАР: текущая полнота
после административных изменений не гарантируется. Состав территорий сохранён
по источнику. Для городов внутри Москвы/Санкт-Петербурга явно сохранён их регион
и Europe/Moscow; для Крыма/Севастополя — Europe/Simferopol. Одноимённые города
не объединяются. При обновлении источника нужно повторить проверки уникальности
пары название/регион и часовых поясов; не менять существующие UUID.

## Загрузка

На среде с настроенным доступом к нужной БД:

```sh
npm run db:seed-cities --workspace=@ustal/database
```

Обычный db:seed также вызывает этот загрузчик. Он выполняется в транзакции с
advisory lock, добавляет отсутствующие пары название/регион и не изменяет UUID,
isActive и существующие связи. Повторный запуск добавляет 0 строк. Миграция схемы
не требуется. Не запускайте полный demo seed только ради обновления городов.

После загрузки проверить GET /cities, поиск, регистрацию тестового пользователя
и изменение города в его личных данных. Локальное превью использует данные
снимка и демонстрационные id; оно не проверяет сохранение в production.
