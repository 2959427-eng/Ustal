## Доказательства по слоям

- `packages/database/src/schema.ts`: users, profiles, sessions, installations, media, profile_source_inputs, facts/decisions/embeddings, orders, responses, assignments, reviews, reports, audit_logs, ai_runs, ai_review_cache, consent/blocked work.
- `apps/api/src/routes/{auth,me,users,contacts,orders,responses,media,reports,blocks}.ts`: сбор, self/peer/admin boundaries; `users.ts` не отдаёт телефоны. Media доступ не равен публичному URL для всех.
- `apps/api/src/lib/account-deletion.ts`: точный list purge/tombstone/cancel/409; migration0026 guard и0027 cleanup.
- `apps/worker/src/handlers/`, `matching-run.ts`, `ai-review-cache.ts`; `packages/ai/src/providers/openai.ts`, `review-fingerprint.ts`, `record-run.ts`: серверный AI/эмбеддинги/голос/модерация/кэш. Input text может включать персональные сведения из свободного текста; «не передаём никаких персональных данных AI» неверно.
- `packages/storage/src`, `apps/mobile/src/notifications`, `apps/worker/src` notification handler: S3 и push; user-agent/IP/device identifiers не рекламный tracking автоматически.
- `apps/mobile/app.json`, SDK dependencies, PhotoPicker, avatar-image, VoiceRecorder: camera/photos/mic/push; no GPS/contacts permission found. Android broad media/storage/transitive permissions требуют native merged-manifest audit, не только app.json. В этом candidate портирован app.json diff5318714: broad image/video permissions запрещены через blockedPermissions; настоящий merged Android manifest/AAB ещё не проверен.

Не выводились raw production content, tokens, env secrets или пользовательские строки. Runtime metadata проверялась только allowlist значений: provider, endpoint origins, storage provider, consent mode, log level. Точные region, subprocessors, training use, AI retention не подтверждены; нужна договорная проверка владельца.

`packages/validation/src/profile-facts.ts` и `apps/worker/src/profile-facts.ts` запрещают хранение structured facts с sensitive=true и дополнительно фильтруют чувствительные признаки. Это не исключает наличие чувствительных сведений в исходном сообщении/голосе или их обработку AI до фильтра. Не использовать этот guard для ложного заявления «health/sensitive data никогда не обрабатываются».
